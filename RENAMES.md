# The corporate rename sweep (draft, r711)

Owner's brief: rename most nature-adjacent Tricks into 1970s-to-early-90s corporate and
self-improvement language. Birds stay. Families keep a shared flavour (runs with runs, sets
with sets, flushes with flushes). Rank names mostly stay. Settle the Inseparable pairs'
synergies BEFORE naming the fused Tricks. Last step: change the Trick ids to match.

Order of work:
1. Owner picks names from section 4 (and section 1 / 2 for anything better).
2. Owner rules on section 5 (pair changes); those land as their own commit.
3. Display-name sweep: `name:`, v6 names, and every text that prints an old name.
4. The id sweep (section 7).

Nothing in this file is built yet.

## 5. Inseparable pairs: the synergy review

Verdicts: **adds reach** (the fused Trick fires in more places than both parts),
**multiplies** (one part's payout feeds the other's), **plain sum** (one slot instead of
two, nothing else), **loses reach** (the fused Trick fires in fewer places than the two
did), **loose** (the parts barely touch).

**One finding cuts across four pairs.** A fused line Trick keeps ONE line, the first part's
by tray order (`inseparableCheck`, js/inseparable.js); the other part's line is pruned.
Right Place & Time, Short Circuit, Advanced Interrogation and Lidar each had two lines and
end with one. Stronger per card, but on half the cells. Proposal for all four: **the fused
Trick keeps both lines, and both effects pay on either.**

|---|---|---|---|---|---|

## 7. Trick ids: the final step

**Feasible, as one careful commit after the names are settled.** Every Trick id would
become its display name in snake case (`fast_track`, `team_player`), including Tricks whose
names do not change but whose ids are stale (`magpie` is Hyperphagia, `still_water` is Eagle
Eye, `kindred` is Quake today).

What it touches, measured on r710:
- About **2,700 references** to the 200 Trick ids across js/ and css/: `name:` rows, BAL
  rows, `DESC_TEMPLATES`, `IMPROVE_PLAN` / `IMPROVE_STEP`, `TRICK_CATEGORIES`, `TRICK_NEEDS`,
  `INSEPARABLE_PAIRS`, `V6_NAMES`, tags tables, `hasTrick('x')` / `TB('x')` calls,
  `POSITION_ASSIGN_IDS`, the banned sets, tools/sim, the trick sheets.
- **A blind search-and-replace is not safe.** Several ids are ordinary words used elsewhere:
  `interest` (47 hits, also the interest payout), `overtime` (also the event's id),
  `mirror`, `ripple`, `encore`, `critical`, `compound`, `rhythm`, `swift`, `summit`. The
  sweep must rewrite only Trick contexts (quoted ids, `BAL.<id>`, object keys in the Trick
  tables) from a reviewed old -> new table, and the leftovers are checked by hand.
- **Saved state** holds old ids: a saved run (`trickTray`, owned lists, per-Trick counters
  in SAVE_VARS), and stores keyed by id (`lethe.tierSeen.v1`, discovery,
  `lethe.inseparable.v1`, `lethe.builds.v2`, `lethe.trickTour.v1`, test drive, records). One
  table, `TRICK_ID_RENAMES` (old -> new), read once at load, rewrites them and writes back,
  like the `mythic` -> `legendary` alias. Builds' run stats are keyed by NAME, so old names
  go in the same table.
- Verify: the syntax check, the sim harness, the Trick tour through all four tiers with no
  timeline drift, an r710 save loading with its Tricks, tiers and lines intact.

Knacks that were once Tricks (Move as One, Rain Check, Wait For Iiiit) already have ids that
match their names.
